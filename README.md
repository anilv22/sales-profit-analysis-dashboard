# Sales Data Analysis Project

## 📊 Project Overview

This project focuses on cleaning, analyzing, and visualizing sales data.

## 📁 Files Included

* `clean_sales_data.py` — Python script for cleaning the sales data.
* `create_sales_dataset.py` — Python script for creating the sales dataset.
* Original Excel file — Raw sales data.
* Cleaned Excel file — Cleaned sales data.
* CSV file — Sales data in CSV format.

## 🛠️ Tools & Technologies

* Python
* Pandas
* Excel
* CSV
* Power BI

## 📈 Analysis & Visualization

The cleaned sales data was used to create interactive visualizations and dashboards in Power BI.

The dashboard includes sales, profit, categories, products, and other useful business insights.

## 🎯 Project Goal

The goal of this project is to demonstrate data cleaning, data analysis, and data visualization skills using Python, Excel, and Power BI.
